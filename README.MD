RPS Arena is a fun and interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript. The game allows players to enter their name, challenge the computer, and compete to see who reaches 5 points first. It features a clean warm-themed design, interactive SVG buttons, score tracking, and a responsive layout that works on both desktop and mobile devices.

This project was created as part of my JavaScript learning journey. It helped me practice DOM manipulation, event listeners, functions, conditional logic, and dynamically updating the user interface with JavaScript. I also gained experience using Git, GitHub, and GitHub Pages to manage and deploy a real web project.

When the game starts, the player enters their name on the welcome screen and clicks Start Playing. The game then displays the main arena, where the player can choose Rock, Paper, or Scissors. Each round compares the player’s move with the computer’s randomly generated move, updates the scoreboard, and displays the result of the round. Once either the player or the computer reaches 5 points, the game announces the winner and disables the choice buttons until the player clicks RESET to start a new match.

The project is built using HTML5 for the structure, CSS3 for styling and responsive design, and Vanilla JavaScript for the game logic and interactivity. The repository includes index.html, style.css, script.js, and an images folder containing the SVG icons used for the game buttons.

One of the most valuable parts of this project was learning how to connect a local project to a GitHub repository, push commits using Git Bash, and deploy the finished project online using GitHub Pages. It represents an important milestone in my transition from learning basic web development concepts to building complete interactive applications.

In the future, I would like to improve RPS Arena by adding sound effects, win/lose animations, difficulty levels (Easy / Hard), a round history panel, and a player-vs-player mode. These enhancements would make the game feel even more engaging and polished.
